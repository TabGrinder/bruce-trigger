# Bruce Trigger 1.0 Release

Bruce Trigger brings USB control and screen mirroring to Android for the **LILYGO T-Embed CC1101** running **Bruce firmware**.

## Features

- Rotary navigation and on-screen controls.
- Mirroring for supported Bruce menus and graphics.
- Custom-theme support.
- JavaScript games launched from Bruce's Files menu.
- An included Megalodon adaptation.

## Installation

Download **Bruce-trigger-1.0.apk** below and install it on your phone. Connect the LILYGO with a USB data cable, open Bruce Trigger, tap **CONNECT** and allow USB access.

Requires **Android 8.0 or later** with USB host / OTG support and **Bruce 1.16.1**. The source code, documentation and APK checksum are included in the release assets.

## Known limitations

Bruce Trigger works with custom themes, but the default theme provides smoother performance. Some games and graphics cannot be fully mirrored, animated GIF themes show a still preview, and switching away from the app closes the USB connection.

See [Known limitations](https://github.com/TabGrinder/bruce-trigger/blob/main/docs/KNOWN_LIMITATIONS.md) and [Validation](https://github.com/TabGrinder/bruce-trigger/blob/main/VALIDATION.md) for compatibility and test status.
